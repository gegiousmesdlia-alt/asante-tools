Customer-Service Training Data

This is a separate tool from the admin panel on purpose — it only generates or clears simulated buyer conversations for practicing/evaluating customer-service response speed and quality. Seeded conversations write into the same "messages" data the admin panel's Messages tab reads, so whoever is doing the training exercise replies from there — this tool itself has no inbox view.

Seed training conversations

Adds ~14 varied simulated buyer inquiries — different phrasing, different scenarios (frustrated customer, skeptical customer, terse one-liners, a rapid double-message, a genuinely complex question, and a full example exchange showing one good way to handle an unverifiable "I already paid" claim). None of these are real accounts, and none assert a payment as settled fact.

Clear demo conversations

Deletes every conversation this tool created. Run this before real customer traffic starts using the admin panel's Messages tab.
